# Proposed-line form

Use this form for anyone who describes a line. The line can use an existing label, a new label, or be a seller's proposal.

Work the steps in order. Stop at the first step that gives a result.

| Step | Question |
|---|---|
| 1 | Do the units already have a line (first sentence of the rule)? If yes: **Placed.** Exception: if the proposal counts its price on an attention measure in place of the format's own price basis, it claims a new price basis (reading notes 2 and 6). Its units are then not the same units. Go to step 2. |
| 2 | Does the proposal state a route: a currency or a record? If no: **Not a boundary.** Name what is missing. |
| 3 | Currency route: does it pass the exchange check, with a counter that is not the host? Record route: does the comparison meet the four requirements? |
| 4 | Does the boundary sort items before the buy? Does someone other than the seller decide membership? Can a buy fail? |
| 5 | If steps 2 to 4 pass: **A boundary on paper.** State what must be shown in practice. |

## Results

The form returns three results only.

| Result | Meaning |
|---|---|
| **Placed** | The units already have a line. Name it. |
| **Not a boundary** | The proposal states no route, or fails step 3 or step 4. Name the failed step. |
| **A boundary on paper** | The description passes. It returns what its route shows. State what must be shown in practice. |

The form never returns "a line" from a description. Practice must show it (see "On paper and in practice" in the [rule](../line-test/RULE.md)).

A result applies to the description given. It is not a verdict on any seller or on any buy.
