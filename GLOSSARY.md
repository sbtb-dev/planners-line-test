# Glossary

Terms are used the same way in every file.

| Term | Meaning |
|---|---|
| **format** | The form an ad takes, such as display, video, audio, or a sponsorship. |
| **unit** | A format plus its terms and its currency. It is what a buyer buys. |
| **currency** | The same defined event, counted the same way by every seller, by a party that is not the host. |
| **terms** | The conditions of the buy: what is counted, how it is paid for, and for how long. |
| **line** | Budget with one owner and one benchmark. |
| **native line** | A line that already exists in a plan and already compares the unit with the same unit from other sellers. |
| **boundary** | The rule that decides what may enter a line. |
| **channel** | A seller's word for where media is made or sold. No rule decides what a channel is. The test does not use the word. |
| **venue** | The place or surface where the ad appears, such as a game, a site, or a screen. |
| **host** | The party that runs the venue. |
| **label** | A word a seller puts on an offer in place of a unit, such as "gaming." |
| **media engagement** | What people do with the venue or the format. The venue produces it with any brand, or with none. |
| **brand engagement** | What people do because the brand is there. |
| **exposed population** | Everyone the buy reached, not only those who took part. |
| **comparison** | A reading that sets the brand's result beside a result with the venue held constant. Only the difference is the brand's. |
| **record** | Terms written in the order before the buy: the unit, the exposed population, a comparison, and a verifier. |
| **verifier** | A party that checks the record. It is not the seller. |
| **on paper** | The description of a boundary passes the test. The evidence is the description. |
| **in practice** | Data, records, or an audit show that the boundary works. |
