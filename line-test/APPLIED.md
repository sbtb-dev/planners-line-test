# Worked cases

Each case applies the [rule](RULE.md). Cases marked "hypothetical" are invented to show how the test works. They are not reports of real offers.

## CTV

The format is video. The format did not change. The unit did, because the price basis changed. CTV counts households. It has its own currency. The way CTV is bought is a term, and the line predicts it. The term alone did not make the unit. A line was earned because the currency route was met, and practice has shown it: a counter that is not the seller counts the same event across sellers.

## Mobile gaming

Mobile gaming changed the venue. It did not change the unit. Sellers sell the same in-app units, through the same pipes, with the same measures. Attention may be higher. That is a property of delivery, and it is compared within the line. The unit is placed. No new line is needed.

## A gaming line

A "gaming line" holds many unlike formats: display, video, audio, creator content, sponsorship, and more. They share a venue label. They share no unit.

The label fails in two ways:

- **A wide label breaks comparison inside the line.** One line holds units that cannot be compared with each other.
- **A narrow label breaks comparison outside the line.** A mobile-gaming line keeps a unit away from the same unit sold elsewhere. This is the mobile gaming case above.

The label predicts no unit, no terms, and no return. Each unit goes to its own line.

## In-game branded content, as commonly described

Public descriptions give this item as a brand becoming part of a world that players have chosen. That describes a shape. It does not state a route. No shared event is defined. No comparison is written into the order. The description does not meet the second sentence of the rule. It is not a boundary.

## An in-world impression with an independent counter (hypothetical)

Suppose a proposal defines one event: an impression inside a world. Suppose a party that is not the host counts it, and the count is the same across sellers. The proposal then states the currency route. It sorts items before the buy. The seller does not decide membership. A buy can fail.

This is a boundary on paper if the event it defines is new. It returns exposure. Reading note 5 limits its price to exposure. Whether it holds in practice depends on the data.

One check comes first. The IAB, IAB Tech Lab, and MRC already publish counting rules for an impression on an in-game object. If the proposed event is the same event, the first sentence of the rule places the unit (display or video), and the result is Placed. Only a different event can be a boundary on paper.

A rival boundary can pass the test. This is intended. A test that only one boundary could pass would not be a test.

## The performance line

A performance line holds many formats: display, video, search, social, and more. They share one price basis: an action, such as an install. The line is defined by the price basis, not by the format. Under note 2, a unit is a format plus its price basis, and a line can compare units that share a price basis. This is an existing line. The test does not re-examine it (section 5 of the rule).

## A gaming attention line

Suppose a proposal holds display, video, and audio units in games. Each unit has an attention score. The units are the same units that other sellers sell. Attention is a property of delivery (note 2). A higher score can earn a higher price within the line. It does not change the format or the price basis, so it does not make a new unit (notes 6 and 7). The result is Placed. Each unit goes to its own line.

## A cross-media line priced on attention

Suppose a proposal prices many formats on attention, across all venues. A gaming venue does not decide this case. Units from games enter such a line as display, video, or audio units. They are compared with every other seller.

The IAB and MRC published *Attention Measurement Guidelines*, Version 1.0, in November 2025. The document was read on 20 November 2026. It standardizes the definitions of attention metric categories, minimum requirements, validation, and disclosure. It says it does not stipulate which measurement approach is best. It does not define one shared number that every seller counts the same way. Each vendor keeps its own method.

So the line fails the exchange check (3.1). A buyer cannot swap 1,000 units of attention from one vendor for 1,000 from another and expect the same thing. The result is Not a boundary. If one shared number existed, counted the same way by every seller through a party that is not the host, the line could be a boundary on paper by the currency route. Its price would be limited to exposure (note 5).

## Intrinsic in-game display

The IAB, IAB Tech Lab, and MRC publish counting rules for a viewable impression on an in-game object. A seller can claim that a 3D object in a world is a new unit. The format is display. The price basis is a viewable impression. Size, placement, and context are compared within the line (note 7). A standard written for in-game objects does not create a new price basis if it adapts the display price basis to the venue (note 8). Then the first sentence of the rule places the unit in display. The final in-game guidelines keep the display viewable test and add conditions for screen coverage, angle, and occlusion. The repo owner reads these as an adaptation, so the unit is placed in display. If a standard defines a different event, the exchange check (3.1) decides. See the mapping's section on the item with no native line.
