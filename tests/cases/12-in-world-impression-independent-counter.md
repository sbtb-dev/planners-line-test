# The same, counted by an independent party

**Type:** Proposed line

## Input

> We propose a line built on one defined event. An in-world impression is one event: a branded object is rendered on a player's screen at ten metres or less. The event has no minimum pixel share and no minimum time. A party that is not the host counts it, the same way on every platform. Membership is set by the definition, before the buy. A buy can miss its count.

## Expected result

**A boundary on paper.** The currency route is stated and passes the exchange check. The boundary sorts before the buy, the seller does not decide membership, and a buy can fail.
- It returns exposure. Note 5 limits the price to exposure.
- State what must be shown in practice: the independent count, across sellers.

**Note for the reader of the answer:** the answer should check whether the proposed event differs from the impression that published in-game measurement rules already define. If it does not differ, the unit is Placed. The input defines an event that differs: it has no pixel share and no time condition, which the published viewable impression requires.
