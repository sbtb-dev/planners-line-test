# A brand builds and runs its own game

**Type:** Offer

## Input

> We are a brand. We built our own game and we run it. We will buy media to bring players to it. We will report visits and session time.

## Expected result

- The build is production (scope 6.4). No seller exists.
- The media that brings players goes to that media's own lines. Confirm the units.
- The presence inside the game has no record stated. Production plus delivery. Visits and session time are media engagement.
- The party that builds and runs the surface does not decide membership (scope 6.4, note 4). Report only.
