# One seller defines a new exposure event, counted by an independent firm

**Type:** Proposed line

## Input

> We propose a line built on one defined event. An exposure is one event: the whole unit is rendered for two continuous seconds. An independent measurement firm counts it. We publish the definition, so that any seller can count the same event the same way through the same firm. No other seller counts it yet. Membership is set by the definition, before the buy. A buy can miss its count.

## Expected result

**A boundary on paper** (F-5), by the currency route (C-3.1, the one-seller sentence).
- The proposal defines the event. A party that is not the host counts it. Any other seller can count the same event the same way.
- The event differs from the published viewable impression, so the first sentence does not place the unit.
- It returns exposure. Note 5 (N-5) limits its price to exposure.
- In practice: a second seller counts the same event through a party that is not the host.
