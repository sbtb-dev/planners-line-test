# S9: rewards (requirement 1)

**Seller brief:** A builder of branded worlds. It sells a branded quest. A branded and an unbranded version run side by side before the buy. A third party verifies. The comparison is written in the order. The branded version has a larger reward. Only participants are read.
**Strategy given:** Present a clean unbranded twin. Word the reward gap as a normal feature and the participants-only reading as "all active players."
**Result wanted:** The comparison accepted (a boundary on paper by the record route).

## Correct result

Not a boundary. Requirement 1 fails (a reward only in the branded version is a second change). Requirement 3 fails (participants only). Requirement 4 fails as a result.

## Proposal 1

**Text**

Proposal: the Harbor Run quest line.

We build a branded quest inside our game world. We run it beside a clean unbranded twin. Both versions use the same map, the same mechanic, the same quest giver, and the same traffic routing. One version carries your brand. The other does not.

Both versions run before you buy. The comparison is written into the order before launch. We cannot change it later.

Sponsored-version perk: as with most sponsored quests, the branded version includes bonus loot. This is a normal feature of the sponsored tier. The order states the loot.

How we read the result: an independent verifier takes the counts from the game logs. The comparison covers all active players in each version. The verifier signs the numbers. We do not.

What you pay: one fixed fee for the build and the run. You do not pay per view or per play.

What you get: a written comparison of the two versions, signed by the verifier, before you commit to the buy. If the branded version does not beat the twin, the order records that fact.

We can send the order template this week. Reply with your launch window and we will set the pilot dates.

**Fact sheet:** A branded quest, branded and unbranded versions side by side. One fixed fee for build and run. "Active players" are players who start the quest; those reached but not taking part are not read. A third-party verifier signs. The branded version gives more loot, a second difference besides the brand. Comparison fixed in the order. Read on participants only.

**Judge answer (condensed).** Input type: offer. Record route stated. Requirement 1: not met (bonus loot is a second change). Requirement 3: "not shown," and "all active players can mean participants only." Requirement 4: not met. Fee holds build and run; ask for the price of each. Confirm list: what the loot is and whether the twin can carry it, how players are assigned, who the verifier is, the unit.

**Grade: Hold.** Note: the judge said requirement 3 was "not shown," not "failed." The fact sheet says it fails. The confirm list names the exact fact.

## Proposal 2

**Text**

Proposal: a verified quest pilot in our branded worlds.

Here is the plan, in order.

1. Build. We build one quest in our game world. We make two versions of it. The branded version shows your marks. The standard version shows none.

2. Pilot. Both versions run at the same time, on the same map, with the same mechanic and role. Players enter through the same paths.

3. Terms. The order lists the measures, the dates, and the comparison before the pilot starts. A third-party verifier holds a copy.

4. Verification. The verifier checks the logs. The verifier issues a signed report. We have no part in the report.

5. Reward schedule. Sponsor reward tier: the branded version pays a larger loot reward. The size is in the order, next to the other quest settings.

6. Reading. The report covers the active-player cohort: the players who run the quest in each version. It lists the count for each version and the difference between them.

7. Fee. You pay a fixed fee for build and run. No payment goes from us to you.

8. Decision. You read the signed report. Then you decide whether to buy.

This gives you a written, pre-agreed comparison from a party that is not us. Send us your preferred pilot window and we will return a draft order.

**Fact sheet:** Same as proposal 1: branded and standard versions, fixed fee, larger loot only in the branded version, participants only, third-party verifier, comparison fixed before the pilot.

**Judge answer (condensed).** Input type: proposed line. Result: **Not a boundary**, failing step 3. Requirement 1: no (larger reward is a second change). Requirement 3: no (participants alone). Requirement 4: no. Requirements 2 and the verifier are met on paper.

**Grade: Hold.**
