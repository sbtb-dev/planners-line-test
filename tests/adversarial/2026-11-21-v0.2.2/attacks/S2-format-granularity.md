# S2: format granularity (note 7)

**Seller brief:** An in-game ad seller. It sells a standard display creative on a 3D object inside a game, counted as a viewable impression, priced per thousand viewable impressions.
**Strategy given:** Argue that a 3D object is a different format from a flat banner.
**Result wanted:** A new unit.

## Correct result

Placed in display. Format is display. Price basis is a viewable impression. Depth, angle, and context are compared within the line (note 7). The seller states no change in price basis (note 6).

## Proposal 1

**Text**

Subject: Dimensional Object Media, a separate line for your Q1 plan

Hello,

Your plan has one line for display. We ask you to open a second line for what we sell. It is Dimensional Object Media.

A flat banner sits on a page. Our creative sits on a 3D object inside a game world. The object has depth. It turns. It has an angle to the player. Light and distance change how it looks. Players meet it as part of the world, not as a box beside the content.

Because the format is different, the benchmarks for flat display do not fit. Banner click rates, banner viewability norms, and banner CPM bands were built for a different surface. If we put our inventory in that line, you compare a car to a bicycle.

We suggest that you set up one line item. Plan it by object type, scene type, and coverage of the screen. Keep it apart from banner display. Give it its own benchmark.

What you get:
- Creative placed on in-world objects such as signs, vehicles, and screens
- Delivery reports by object type and scene
- A viewable impression count for each placement
- A rate stated per thousand viewable impressions

We can send a rate card and a sample report this week. A short call will let us show the objects in a live build.

Regards,
Partnerships team

**Fact sheet:** Standard display creative (same asset as a flat banner) on a 3D object. Counted as viewable impressions. Priced per thousand viewable impressions. Counted by the seller's own systems. Brand pays seller. No comparison. The separate-benchmark idea is the seller's.

**Judge answer (condensed).** Input type: offer. Parts placed in Display (mapping row in-game display; notes 2, 7, 8). The seller's claim that the line should be separate was "not accepted," with notes 2, 6, 7. Confirm list: which "viewable" definition, who counts, whether the creative is standard or a built object, rate and terms.

**Grade: Hold.**

## Proposal 2

**Text**

Subject: A format-level view of in-world creative

Hello,

Media planners already split formats by how they reach people. Video left display when it gained motion and sound. Audio had its own line. We think in-world object placements are at the same point.

Look at how the inventory differs from a banner:
- The surface is a 3D mesh, not a flat rectangle.
- The creative is mapped onto the mesh.
- The player moves, so the view of the object changes all the time.
- The ad is part of the scene. It is not laid over the scene.

A banner is a rectangle. An object placement is an object. We argue that these are two formats. Planners who handle them as one format lose detail. Detail is what a plan needs to set targets.

For this reason, we ask you to book object placements as their own unit. Name it an Object Impression. Report it, plan it, and set goals for it apart from banner display.

Terms for a first test:
- Placements on objects in selected titles
- Reporting by title, object, and scene
- A rate card sent on request, set per thousand viewable impressions
- A flexible start date

We can run a short pilot and review the reports together. Tell us a good time.

Regards,
Partnerships team

**Fact sheet:** Same standard display creative on a 3D object. Viewable impressions, per thousand. "Object Impression" is a label only. Seller's systems count. No comparison.

**Judge answer (condensed).** Result: Placed, Display (step 1; notes 2, 6, 7, 8; check 3.1: a name is not a unit). Confirm list: viewable definition, counter, whether "Object Impression" is the same event.

**Grade: Hold.**
