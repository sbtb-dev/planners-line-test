# Fixture 11: run through the prompt, v0.4.0

Route: prompt/PROMPT.md. A fresh subagent. Input given:

> We propose a line built on a verified in-world impression, sold on two platforms. Each platform counts its own impressions and reports them.

## Answer

**Input type:** A proposed line. I use the proposed-line form.

**Result: Not a boundary. Failed step: F-3.**

| Step | Finding | Cite |
|---|---|---|
| F-1 | The input does not state the format. It does not say what is shown. It says only "in-world impression." An impression is a way of counting. It is not a unit. I cannot place the units with the first sentence of the rule. | C-3.1, N-2 |
| F-2 | The proposal states a route. It is a currency: an impression count that is "verified." It states no record. | N-3 |
| F-3 | It fails. Each platform counts its own impressions. The host counts, not a party that is not the host. The input names no one event that both platforms count the same way. So a buyer cannot swap 1,000 from platform A for 1,000 from platform B and expect the same thing. The count is not a currency yet. | C-3.1, N-3 |
| F-4 | Not reached. Note: the input does not say who decides membership. The input does not say who verifies. The input does not say how a buy can fail. | N-4 |

**Two readings of "in-world impression."**

| If the offer is... | Where it goes | Cite |
|---|---|---|
| A standard creative in a slot inside the world | Display or video, by the first sentence of the rule. The line is Placed. Compare on the display or video unit. | M-01, M-03, F-1 |
| A brand's presence inside play (a branded world, an integration, a skin, a product placed in game content) | No native line. It needs a currency or a record. A currency fails as shown in F-3. The input states no record. | M-27, M-22, N-3 |

The input does not say which reading is true. I do not supply the format. The result above applies to the description as given.

**Notes on the claim.**
- "Verified" is the seller's claim. The input does not say who verifies. The input does not say what the verifier counts.
- Any engagement count that comes with the offer is media engagement. No comparison is stated. (C-3.2, R-1 to R-4)
- Counts inside play are not the same as display or video impressions. A count that adapts the display price basis to the venue does not create a new price basis. A count of a different event can. The exchange check decides which. (N-8, C-3.1)

**What to confirm.**
- The format: what is shown, and in what slot.
- The price basis of the buy. For example, a viewable impression, a completed view, or another measure. If the price is counted on a measure that is not the format's own, the unit is unplaced. (N-9)
- The event that each platform counts. Ask for the written definition from each.
- Who counts: the platform, or a party that is not the host. Ask if a third party audits both counts.
- What "verified" means, and who does it.
- Whether the two platforms count the same event in the same way.
- Whether a record is in the order before the buy. It must state the unit, the exposed population, a comparison that separates the brand from the venue, and a verifier. (N-3, R-1 to R-4)
- The currency and the terms.
- Who decides which items enter the line.
- How a buy can fail.

**What would change the result.** One event, counted the same way by a party that is not the host, on both platforms. Or a record in the order that meets R-1 to R-4. Then the form can reach F-4 and F-5. The result would be at most "A boundary on paper." Practice must then show it.
